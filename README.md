# User Manual and API Documentation

Author: Thon Yien Thon

## Project Overview

This project contains two documentation exercises:

### A. User Manual Procedure
A step-by-step guide on how to create a GitHub repository and make the first commit. It covers prerequisites, installation, repository creation, Git commands, troubleshooting, and screenshots.

### B. API Reference Entry
Documentation for a hypothetical REST API endpoint that allows authenticated users to create tasks in a project management application.

HTTP Method: POST

Endpoint:`/v1/projects/{project_id}/tasks`

The API supports task titles, descriptions, assignees, due dates, and priority levels.
